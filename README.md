# asr-cloud-26
Repo asignatura Arquitectura Sistemas Red 2026-27: enunciados de prácticas.

Cada carpeta numerada corresponde a una práctica. Las carpetas cuyo nombre termina en
**"-Entrega"** son las que hay que entregar; el resto se realizan en clase y no se
entregan. Cada práctica incluye únicamente el enunciado y los ficheros de apoyo
necesarios para resolverla (código dado, plantillas de configuración, imágenes de
referencia, etc.), sin la solución.
